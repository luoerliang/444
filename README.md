# 澳门六合彩3分分析（免 Token）

数据源：澳门六合彩3分公开历史页：`https://maoaujc.com/macaujc2//?id=3&page=3`

Render Start Command:
`gunicorn app:APP`

本版本：
- 只处理 3分 issue 格式
- 严格要求 6 个正码 + 1 个特码才写入
- 自动去重
- 北京时间 UTC+8
- 页面每60秒刷新，服务运行时后台每60秒同步
- 网页打开后可点“立即同步”
- 统计候选仅为历史频次统计，不保证结果

注意：Render 免费实例休眠后无法在后台持续运行；用户打开网页时会再次同步。SQLite 在免费实例重启/重新部署时不保证永久保存，如需长期保存应改用持久磁盘或 Postgres。
