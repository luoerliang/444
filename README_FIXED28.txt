固定28：基于第16版基础改进
1. 不删除已有历史；Telegram机器人数据优先，历史CSV只补缺，不覆盖机器人原始顺序。
2. 内置三分历史.csv：2026-08-16起的历史，共14343条；其中8/25-9/8每天480期，全部纳入统计。
3. 内置已提供的机器人近期记录，并继续实时接收Telegram。
4. 预测22码：01-49全部评分，继承第16版多窗口/频率/遗漏逻辑，增加生肖/波色独立走势、转移、重复率自适应。
5. 上一期特码不机械带入下一期；只有历史重复倾向支持时才保留。
6. 生肖：只预测1个生肖+1个号码；不再固定马鼠牛猪猴。
7. 波色：独立预测下一期红/蓝/绿。
8. 历史开奖6个正码严格保持机器人/原始CSV顺序，不排序；22码才按数字升序。
9. 页面复制22码只复制数字，格式01,02,...。
Render：Build pip install -r requirements.txt；Start gunicorn app:app；环境变量 TELEGRAM_BOT_TOKEN 填机器人Token。
