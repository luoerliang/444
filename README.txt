第16版基础·固定历史不删版·算法优化30

核心原则：
1. 不删除数据库已有历史；启动只做“缺失期号补种”。已有 Telegram 数据优先级最高。
2. 随包保留 history_seed.csv（14,343期）+ robot_seed.json（58条机器人记录），合并已知历史14,401期。
3. 历史开奖6个平码严格保持机器人/原始顺序；特码独立显示在 + 后。只有预测候选码按01→49升序。
4. 预测只使用历史特码，不把6个平码混入特码评分。
5. 第16版基础动态评分继续保留：6/12/24/48/96/192/384窗口、长期频率、遗漏、重复抑制、波色转移、生肖转移、单双大小。
6. 动态码数修正为20～22码，最多22码；每期开奖后重新对01～49全部评分，因此号码会变，不固定01～22。
7. 特肖继续独立模型：近期频率、遗漏、生肖转移、近期过热惩罚；前5个生肖，每个2个号码。
8. Telegram接收支持 message/channel_post/edited_message/edited_channel_post + caption。
9. 增加“自动恢复种子”保护：Render重启或SQLite为空时自动恢复随包历史，不会因为数据库为空而出现整页空白。
10. 历史回测仅用于衡量模型表现，不代表下一期结果，也不保证命中。当前随包回测基准：19码38.75%、20码41.25%、21码43.50%、22码45.62%、动态19～23码46.50%（这是第29版缓存的历史基准，版本30不会伪造新的命中率）。

部署：
Build: pip install -r requirements.txt
Start: gunicorn app:app
环境变量：TELEGRAM_BOT_TOKEN

重要：不要删除 history_seed.csv / robot_seed.json / backtest_cache.json。
